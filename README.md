# Program Rekapitulasi & Analisis Nilai Matematika Kelas

## Deskripsi
Program berbasis Python console untuk membantu guru matematika membaca data nilai siswa dari file teks, memvalidasi rentang nilai, menghitung statistik kelas (rata-rata, minimum, maksimum), menentukan status ketuntasan KKM, dan menghasilkan file laporan otomatis.

## Fitur Utama
- Membaca data siswa dari file teks (`data/nilai_contoh.txt`).
- Validasi data input (rentang nilai 0 - 100).
- Perhitungan statistik (Rata-rata, Min, Max, Jumlah Tuntas/Belum Tuntas).
- Pembuatan laporan otomatis ke file teks (`output/laporan.txt`).

## Cara Menjalankan
1. Pastikan Python 3.x sudah terinstall.
2. Buka terminal VS Code dan masuk ke folder `src`:
   ```bash
   cd src
   python main.py
